01

The mental shift

You already know how to ask a chatbot a question. The difference here is that Claude Code has hands. It reads and writes files, runs code, queries databases, reads your Outlook and SharePoint, and produces finished .xlsx, .docx, .pptx and .pdf files.

So stop asking it "how would I reconcile client money?" and start asking it "reconcile this." The useful prompt names three things: the goal, the source of truth, and the shape of the output.

Goal:   reconcile the AU client money balance for August
Source: the segregation summary emails + the GL extract in SharePoint
Output: an xlsx with live formulas, one tab per entity, variances flagged

A skill is a saved playbook — house rules Claude follows every time, so you never re-explain the format. Invoke one by name with a slash, or just describe the task and it will pick the right one up.

04

Your first twenty minutes

  1. 01

    Prove the mailbox connection

    Low stakes, read-only, and it shows you the connector working end to end.

    Run /apac-daily-cash-segregation for yesterday.
  2. 02

    Make it produce a real file

    This is the moment most people's mental model updates — a spreadsheet lands, with formulas in the cells rather than hardcoded values.

    Find the last 10 business days of segregation summaries in my mail
and build me an xlsx: date down the rows, entity across the columns,
surplus/deficit calculated by formula, and a line chart of the AU trend.
  3. 03

    Point it at something you actually dread

    Pick the task you'd hand to a junior if you had one. Be specific about the output — "a two-page Word memo", "a 6-slide deck", "an email I can paste into Outlook".

    Read the last three CMAC papers I wrote in SharePoint, then draft the
Q3 one using the same structure. Flag every figure you couldn't source
rather than estimating it.
  4. 04

    Correct it out loud

    Don't restart the conversation when the output is 80% right. Say what's wrong — "the variance column should be signed the other way", "too formal for BDO", "drop the exec summary". It keeps all the context and reworks it.

05

The play worth getting excited about

Standing instruction

Turn the recurring close into something that runs itself

Everything above still needs you to ask. The real unlock is a Routine — a scheduled instruction that wakes Claude up on its own, does the work, and has the result waiting for you.

  • Read the overnight report
  • →
  • Extract the table
  • →
  • Compare to yesterday
  • →
  • Flag the breaches
  • →
  • Draft the email

Set it once and the daily cash segregation position is reviewed, trended and written up before you open your laptop. You read and send — the judgement stays with you, the assembly doesn't.

Set up a Routine for 7:00am Sydney time, weekdays.

Each morning: pull the segregation summary from the approved IGAU & NZ
daily cash report, compare every entity against the prior business day,
flag any movement over 5% or any entity in deficit, and draft a short
note in my voice for the Finance team. If the report hasn't landed yet,
say so rather than using stale figures.

The same pattern fits the rest of the calendar: a Monday pipeline of month-end close tasks, a weekly regulatory-deadline sweep, a quarterly prompt to refresh the peer multiples in a live thesis.

06

Habits that separate good output from great

  • Name the source, always. "From the GL extract" beats "from what you know". Left unsourced, it will reason from general knowledge — which is exactly what you don't want in a regulatory submission.
  • Ask it to flag rather than fill. "Mark anything you couldn't verify" turns a plausible-looking number into an explicit gap you can go and close.
  • Make it show the arithmetic. Formulas in the spreadsheet, not values. Then the workbook is auditable by someone who wasn't in the conversation.
  • Use plan mode for anything material. Ask for the approach before the execution, approve it, then let it run. Cheaper than rereading 40 pages of the wrong thing.
  • One conversation per workstream. Context is an asset — a long-running close thread gets sharper as it goes. Start fresh only when the subject genuinely changes.
  • Turn any repeated correction into a skill. The third time you give the same instruction, say "make this a skill". That's exactly how the three above came to exist.
07

Where the edges are

It can read your mail. It cannot send it. Every Microsoft 365 permission on this account is read-only, so nothing leaves your mailbox without you pressing send. Drafts come back to you as text or a file.

Two things still need your eyes: figures — spot-check the arithmetic against source on anything going to a regulator, an auditor or a board — and anything irreversible, which you'll always be asked to approve first. It will tell you when it couldn't verify something, but only if you've asked it to.
